Данный проект является решением задачи по созданию приложения «Ветеринарная Клиника».
В нем реализовано использование базы данных SQLite с помощью SQLAlchemy.

В этом проекте я постарался реализовать RESTful API на Flask в качестве бэкенда и фронтэнд
который асихронно получает данные от бэкенда в формате JSON.

Реализованы  CRUD операции для моделей Patient, Doctor, Appointment. Также есть таблица MedicalCard.
Пациент и доктор имеют связь многие ко многим (через таблицу Appointment), Медицинская книжка
и пациент имеют связь один к одному.

Чтобы запустить проект:

Находясь в папке backend введите в консоль (предварительно установите все необх. библиотеки):
###python -m flask run###

Откройте frontend\index.html у себя в браузере
